# 地方自治の日数（chiho-jichi）

条例の送付・公布・施行、議会の招集の告示・臨時会・再議、長の不信任と議会の解散・長の退職の申出・予算の提出・決算、住民監査請求・監査・住民訴訟・条例づくりの請求・解散や解職の請求の場面を読んで、その日数か期間（3日・7日・10日・20日・30日・60日・3か月・1年）を当てる1日5問の学習ゲーム。正解したら、どのきまりか（条例と議会／長と予算・決算／住民の請求）も選ぶ。地方自治のきまりの学習に。

遊ぶ: <https://satou-aaaaa.github.io/chiho-jichi/>

- 中身は e-Gov 法令検索の地方自治法（<https://laws.e-gov.go.jp/law/322AC0000000067>）第16・74・79・84・101・145・176・178・211・233・242条・第242条の2に書いてある日数・期間だけです（2026-11-18 に読んだ今の条文）。
- 説明は条文を、短く言いかえたものです。首長や議員の任期・選挙・署名の数や賛成の割合・それぞれの市町村の条例は省いています。公式の情報の代わりではありません。実際のことは、総務省や住んでいる自治体の案内、専門家に確かめてください。
- 選挙のしくみ（senkyo-shikumi）の首長・議員の任期とは重ねていません。
- 2段目は、きまりの種類で分けています。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
